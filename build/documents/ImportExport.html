Saving and Loading a Project

ArchaeoToolbox provides two methods for saving and loading a morphometric project. Before providing more details, it is neccessary to mention that the saving process exclusively save (write on the disk) information of Digitised landmarks and their corresponding geometry (mesh files). Therefore, it is highly recommended to save the project before the superimposition, since superimposing specimens will permanently alter the digitised landmark information and their geometries (landmarks and their mesh domains will be scaled and rotated during the process).

There are two ways to save a morphometric project: 1- saving landmarks without geometry link, and 2- saving landmarks and their geometry domain (3-dimensional mesh). In the first scenario, which is a quick recovery process rather that saving-loading a project, the digitised landmark information (Export data -> Raw Landmarks) can be recovered given that the path to the geometry folder is provided. Saving the landmark data has already been addressed (File menu -> Export Data). The recovery is straight forward: File menu -> Recover (Legacy). This option will ask user to provide the location of digitised landmark file (a .csv file) and immediately afterward it will ask for the location of the geometry meshes. By doing so, 3-dimensional meshes will be loaded and the digitised landmarks will be added to the project. This approach is noticably faster than normal loading-saving process, and demands less resources. However, it has a drawback: if the user changes specimen name at some point, the recovering algorithm will ignore the digitised information since the name of the specimen doesn't agree with the name of the corresponding mesh file, unless user changes the name of the geometry file as well. In addition, all of the geometry files of the digitised specimens must be placed in a single folder.

The alternative is to save the project (File menu -> Save the Project) as a single file containing information about digitised landmarks and their 3d meshes. To load the saved data, you can open the saved file from the File menu -> Open. ArchaeoToolbox will save morphometric projects as ".atp" file (ArchaeoToolbox Project file). Depending on the number of digitised specimens in the project and size of the triangular meshes, the atp file can get very large and the openning process is much slower than the simple recovery process. However, it doesn't have nuisance of the recovery regarding the name changing and the placement of the geometry files.
